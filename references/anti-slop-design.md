# anti-slop-design — what NOT to do + what to do

## NEVER do (AI slop signals)
- Inter/Roboto/Arial as default font
- Purple gradient on white background
- Uniform rounded corners on everything
- Center-only layout
- Generic hero + 3-column features layout
- Same shadow on every card
- Emotionless stock illustrations

## Always do
- Pick an extreme tone: brutalism / minimal / retro-futurism / organic / luxury / editorial / art deco
- Distinctive font pairing (never repeat same combo twice)
- Dominant color + strong accent (don't distribute evenly)
- Asymmetric layout, overlapping elements, diagonal flow
- Grid-breaking elements
- Gradient mesh, noise texture, or geometric pattern backgrounds — never flat solid
- Staggered reveal on page load
- Unexpected hover/scroll interactions

## Quality check
- Not using Inter/Roboto/Arial? ✓
- No purple gradient? ✓
- Not all same border-radius? ✓
- Has asymmetric elements? ✓
- Different fonts/colors from last build? ✓
- Would someone ask "did AI make this?" — if yes, redo ✓
