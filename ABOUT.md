## ⚡ Quick Start

```bash
# 1. Clone repo
git clone https://github.com/oh-ashen-one/website-remake-skill
cd website-remake-skill

# 2. Set up APIs
npm install -g firecrawl-cli
firecrawl login --api-key YOUR_KEY
export AGENTMAIL_API_KEY=your_key_here

# 3. Find a target
./scripts/find-targets.sh "dentist" "chicago" 10

# 4. Analyze existing site
./scripts/scrape-site.sh "https://example-dentist.com"

# 5. Build in Claude Code
# Go to https://claude.com → Claude Code
# Use prompts/full-site-rebuild.md

# 6. Deploy to Netlify
git push origin main
# Netlify auto-deploys: https://rebuild.netlify.app

# 7. Send cold email
./scripts/send-email.sh --to owner@example.com --subject "I rebuilt your website" --url https://rebuild.netlify.app
```
